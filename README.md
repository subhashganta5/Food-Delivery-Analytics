# 🍔 Food Delivery Analytics Dashboard

## 📊 Project Overview

This project focuses on analyzing food delivery business data using **Excel, SQL, and Power BI**.

The objective is to transform raw food delivery data into meaningful business insights related to **sales performance, customer behavior, restaurant performance, delivery efficiency, and order trends**.

The project includes data cleaning, SQL analysis, DAX calculations, data modeling, and interactive Power BI dashboards.

---

## 🎯 Business Objectives

The analysis aims to help understand:

- Overall sales and revenue performance
- Monthly order and revenue trends
- Customer ordering behavior
- Restaurant performance
- Revenue by city and cuisine
- Delivery performance
- Order cancellations
- Customer ratings
- Customer segments and age groups
- Restaurant price categories
- Delivery partner performance

## 🔗 Data Model

A **Star Schema** was created with `Fact_Orders` as the central fact table.

### Fact Table

- `Fact_Orders`

### Dimension Tables

- `Dim_Customers`
- `Dim_Restaurants`
- `Dim_DeliveryPartners`
- `Dim_Date`

### Relationships

```text
Dim_Customers       ──┐
Dim_Restaurants     ──┤
Dim_DeliveryPartners ──┤──> Fact_Orders
Dim_Date            ──┘
````

The model uses one-to-many relationships from the dimension tables to the fact table with single-direction filtering.
